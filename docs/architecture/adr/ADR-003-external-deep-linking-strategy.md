# [ADR-003] 네이버/카카오 지도 딥링크 및 모바일 클립보드 공유 전략 채택

## 상태
**승인됨 (Accepted)** - 2026-09-16

## 맥락 (Context)
여행 서비스에서 지도 연동은 필수 기능입니다. 그러나 네이버 클라우드 플랫폼(NCP)이나 카카오 개발자 센터의 유료 지도 SDK를 직접 웹에 임베딩하고 길찾기 API를 호출할 경우:
1. API 쿼터 제한 및 결제 카드 등록, 도메인 검증 등 5인 초기 개발팀에 불필요한 운영 오버헤드 발생.
2. 모바일 웹 환경에서 임베디드 지도가 화면의 상당 부분을 차지하여 터치 스크롤 제스처 충돌(지도 줌 vs 페이지 스크롤) 문제 발생.
3. 사용자는 서비스 내 미니 맵보다는 자신이 평소 사용하던 네이티브 지도 앱(네이버지도, 카카오맵)으로 길을 찾고 내비게이션을 켜는 경향이 훨씬 강함.

## 결정 (Decision)
**인앱 지도 임베딩 대신, 스팟별 '네이버 지도' & '카카오 지도' 검색 딥링크 URL을 생성하여 외부 앱/웹으로 직접 연결**하기로 결정했습니다.
또한 일정 공유 방식은 서버 DB 저장 링크 대신, **모바일 Web Share API 및 텍스트 클립보드 원클릭 복사**를 채택했습니다.

1. **검색 딥링크 생성**:
   - 각 스팟 데이터에 인코딩된 네이버 지도 검색 URL(`naverSearchUrl`) 및 카카오 지도 검색 URL(`kakaoSearchUrl`)을 사전 구축.
2. **원클릭 클립보드 복사 (`ShareModal.tsx`)**:
   - 총 예산, 권역, 시간대별 스팟 명칭, 대표 메뉴, 가격, 교통편 안내를 친구에게 카카오톡/메신저로 즉시 보낼 수 있는 마크다운 텍스트 포맷으로 복사.
3. **네이티브 공유 시트 연동**:
   - 모바일 브라우저에서 `navigator.share` 지원 시 OS 기본 공유 시트 호출.

## 결과 및 트레이드오프 (Consequences)

### 긍정적 영향 (Pros)
- **외부 API 비용 0원 & 키 관리 제약 없음**: Secret Key 유출 위험이나 트래픽 증가에 따른 비용 과금 원천 차단.
- **최고의 모바일 사용자 경험**: 터치 스크롤 꼬임이 없으며, 사용자가 선호하는 네이티브 지도 앱의 최신 리뷰, 길찾기, 즐겨찾기를 그대로 활용 가능.
- **간편한 소셜 바이럴**: 텍스트 복사 및 모바일 공유를 통해 친구나 동행자에게 즉각적인 코스 공유 가능.

### 부정적 영향 및 완화책 (Cons & Mitigations)
- 웹페이지 내부에서 전체 경로를 한 화면에 시각적으로 조망하는 미니 맵이 부재함.  
  → *완화책*: Phase 2에서 카카오맵 정적 이미지 맵(Static Map) 또는 경량 도보 경로 렌더러를 상단 권역 배너에 보조적으로 추가 검토.
